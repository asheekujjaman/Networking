**Deco X50 Mesh Setup with MikroTik (Full Step-by-Step Guide)**

---

### **Network Goal**

* MikroTik Router = Main DHCP Server
* Cisco 2960 Switch = Network Distribution
* 3 × Deco X50 = Mesh WiFi (Access Point Mode)
* Each Deco will have a fixed (manually assigned) IP

---

### **Step 1: Reset All Deco Units**

* Press and hold the reset button on each Deco for 10–15 seconds
* Wait until the LED indicates reset is complete

---

### **Step 2: Physical Connections**

Connect the devices as follows:

MikroTik → Cisco 2960 Switch → Deco 1 / Deco 2 / Deco 3

* Use LAN ports on all Deco units
* All Deco units connect to the switch

---

### **Step 3: Initial Setup Using Deco App**
Turn on 1 deco.

1. Install and open the TP-Link Deco app
2. Select “Set up a new Deco”
3. Choose Deco X50 model
4. Follow on-screen instructions to complete setup

---

### **Step 4: Change Operation Mode**

After setup:

* Go to: More → Advanced → Operation Mode
* Select: **Access Point Mode**

**Reason:**

* MikroTik will handle DHCP
* Prevents double NAT

---

### **Step 5: Add Remaining Deco Units (Mesh Setup)**

1. Open the Deco app
2. Tap “Add Deco”
3. Power on Deco 2 and add it
4. Repeat for Deco 3

* Ensure all units show as **online**
* Wired backhaul should be automatically detected

---

### **Step 6: Configure MikroTik DHCP**

Ensure DHCP server is active on MikroTik

Example configuration:

* Gateway: 192.168.1.1
* DHCP Range: 192.168.1.100 – 192.168.1.200

---

### **Step 7: Assign Manual IPs from Deco App**

Instead of MikroTik static lease, use Deco’s Address Reservation:

1. Open Deco app
2. Go to: More → Advanced → Address Reservation
3. Assign IPs as follows:

* Deco 1 → 192.168.1.2
* Deco 2 → 192.168.1.3
* Deco 3 → 192.168.1.4

---

### **Step 8: Important IP Rules**

* Do NOT assign IPs inside DHCP range
* Keep all IPs in the same subnet
* Subnet mask: 255.255.255.0
* Gateway: 192.168.1.1

---

### **Step 9: Switch Configuration (Cisco 2960)**

* Default configuration is sufficient
* Ensure all ports are in the same VLAN (VLAN 1)

Optional (advanced):

* Enable PortFast on access ports

---

### **Step 10: WiFi Configuration**

* Set SSID and password in Deco app
* All Deco units will broadcast the same WiFi
* Seamless roaming will work automatically

---

### **Final Checklist**

* All Deco units show online in the app
* Devices receive IP from MikroTik
* Wired backhaul is active
* Roaming works smoothly

---

### **Notes**

* Deco system works best with centralized management
* “Manual IP” in Deco is effectively handled via Address Reservation
* Avoid configuring static IP directly on WAN settings in AP mode

---

**End of Configuration Guide**
